# APIs

> Application Programming Interfaces

소프트웨어 프로그램들이 서로 통신하고 데이터를 교환할 수 있도록 하는 규칙이나 규약의 집합

### WebAPi
- Dom
- NetWork 
- Graphic
- Audio/Video
- Device
- file
- Storage

### Web Apis Security
> 보안이 중요하는 경우 Https 에서만 동작

### HTTP vs HTTPS
- HTTP : Hypertext Transfer Protocol
  - 웹 브라우저와 웹 서버 간의 데이터 교환을 위한 프로토콜
- HTTPS : Hypertext Transfer Protocol Security
  - HTTP 프로토콜에서 보안 기능 추가
